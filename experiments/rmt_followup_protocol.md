# Уточнённый протокол проверки RMT

Зафиксирован до запуска дочернего узла после явного подтверждения пользователя. Родитель `315d9dc5-3e90-4eba-ade3-62ea1ed1b419` установил прибавку центрированного спектра к прогнозу, но не исключил влияние увеличенного бюджета и показал ложные компоненты на шуме. Старые критерии и выводы не переписываются.

## Сопоставимый бюджет

Повторно используются шесть сохранённых траекторий и 978 причинных строк; проверяются контрольные суммы исходной записи, 24 артефактов и отчётов. Новых обучений HASBoost нет. Это повторная диагностическая работа с уже изученными траекториями, не независимое итоговое подтверждение.

Восемь заранее заданных наборов признаков: итерация, текущие признаки, последний риск, история, обычный спектр, RMT второго момента, центрированный RMT и объединённый RMT. Разбиения прежние: исключение целой траектории внутри задачи и исключение целой задачи. RF-регрессор: 300 деревьев, минимум 5 объектов в листе, `random_state=20260902`, один поток, без подбора. Шесть целей — будущие риски бюджетов 25/50/75 и три индикатора превышения 0,10. Прогнозы последних оцениваются как вероятности с помощью оценки Брайера. Старый сбалансированный классификатор порядкового бюджета не изменяется; абсолютные показатели двух разных процедур не смешиваются.

Для каждой исключённой траектории заранее задаются квоты сокращённых шагов: бюджет 50 с долями 0,1/0,3/0,5 либо 75 с долями 0,2/0,6/0,9; остальные шаги полные. Число сокращённых шагов округляется вниз. Основные два сценария — 50 с долей 0,3 и 75 с долей 0,6. У всех вариантов одинаковы не только средние затраты, но и точные количества каждого бюджета.

Решение последовательное: при наличии обеих квот сокращённый бюджет выбирается, если прогноз его опасности ниже средней опасности этого бюджета на обучающих траекториях; при равенстве выбирается полный. При исчерпании одной квоты оставшиеся действия вынужденные. Ни будущие проверочные риски, ни будущие признаки, ни сортировка всего проверочного ряда в выборе не участвуют. Известная длина ряда следует из фиксированного плана 100 деревьев; алгоритм с квотами не предназначен для неизвестной ранней остановки. Отдельно сохраняются вынужденные действия. Оракул с будущими рисками приводится только как недостижимая нижняя граница, не как конкурент.

Условие исследовательского продолжения для заранее заданных центрированного и объединённого вариантов: хотя бы на одной задаче средняя оценка Брайера трёх измеренных бюджетов ниже базы последнего риска и лучше в двух из трёх пар; в **обоих основных квотных сценариях** средняя фактическая опасность ниже каждого из конкурентов последнего риска, истории и обычного спектра, с улучшением минимум двух пар относительно последнего риска. Это консервативная предварительная проверка, не статистическое доказательство и не разрешение внедрения. Стоимость рабочего алгоритма не измеряется; совместный отбор и финальная серия не входят в этот этап.

## Ложные спектральные компоненты

Сто перестановок, уровень 0,05, те же объекты наблюдения и нулевой модели. Сравниваются исходный покомпонентный 95-й процентиль, конечные перестановочные значения p с поправкой Холма и исследовательский одноступенчатый `maxT`. Для `maxT` каждый упорядоченный спектральный индекс нормируется по общей выборке наблюдения и нулевых реализаций, затем максимум нулевых нормированных статистик используется для поправки всех компонент. Включение наблюдения сохраняет симметрию нормировки. Численный допуск прежний. Это кандидатная процедура: условия обменности реального оптимизационного процесса и контроль множества окон не установлены.

Проверяются 24 независимых реализации обычного шума и 24 реализации шума AR(1) с коэффициентом 0,9: 1 024 объекта, 64 выхода, одно окно из 16 итераций, постоянный H. Объекты перемешиваются независимо для каждого выхода, одной перестановкой для всех его итераций и G/H. Регистрируются доля реализаций с хотя бы одной ложной компонентой и среднее число компонент, отдельно по видам шума и центрированию; приводятся точные биномиальные интервалы. Параметры не подбираются по этим шумовым примерам. Дополнительно процедура применяется к заранее сохранённым синтетическим спектрам родителя, не заменяя признаки реальных прогнозов задним числом.

## Функциональные контроли

Первый пример: 4 096 объектов, 64 выхода, 50 снимков, два известных бинарных разбиения. Сигнал одного выхода на примерно 2% объектов определяет лучший полный прирост. Высокоэнергетический шум имеет нулевые суммы в четырёх совместных ячейках разбиений и не определяет их выбор; есть группа коррелированных шумовых выходов. Сравниваются полный выбор, энергетический Top-K, нагрузки выделенного спектрального базиса и заведомо дорогой оракул вкладов. Бюджет структуры 8; последнее — диагностический эталон, не новый рабочий совместный селектор.

Второй пример: 16 точных копий одного выхода конкурируют с редким выходом. Удаление копий без весов сравнивается с объединением G/H и одновременным суммированием штрафов L2. Для одинаковых копий это сохраняет суммарный прирост и значения листьев; для произвольных похожих выходов равенство не заявляется. Используется L2=1. Структура оценивается по выбранным статистикам, но полезность выбранного разбиения — по полным; листья проверяются по всем объектам и выходам. Сохраняются суммы G/H кандидатов для независимого пересчёта.

## Воспроизводимость и остановка

Основной агент — единственный владелец цикла, подагентов нет. Все вычисления через локальный `orx exp run`; команда и окружение прежние. До запуска фиксируются код, конфигурация и этот протокол. После ответа узел замораживается. Две попытки без научного ответа требуют обращения к пользователю; после примерно трёх научных неудач новые настройки не добавляются автоматически. Итог сохраняется в папке темы HASBoost вместе с предсказаниями, квотами, нулевыми спектрами и аудитом. Русский протокол прошёл редакторский проход `edit-russian-technical-text`.

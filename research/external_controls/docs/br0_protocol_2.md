# BR-M: MediaMill — общий базис и адресные поправки

Общие ограничения, роли данных, регулятор и итоговый выбор: [[Протокол H-ABL-BR — две ветки адаптивного бюджета 2026-10-27|основной протокол]]. Sol / xhigh, без подагентов. Сейчас только документ.

## 1. Три отдельных вопроса

**M-C — объединение:** архив накопленной функции с общим базисом оставляет больше полезного ресурса для продолжения, чем отдельные защищённые блоки, при прежнем B и допуске.

**M-B — направления:** обновление подпространства архива при том же ранге 50 полезнее сохранения первоначальных направлений. Смена только координат не считается обновлением.

**M-S — остаток:** при одинаковом числе поправок и памяти распределение их по потерям отдельных меток полезнее прежнего глобального порядка balanced_mse.

Статус всех трёх гипотез — не установлено. Механическая стоимость хранения разных B установлена по сохранённым массивам; способность заменить их одним без существенной потери функции не установлена. Если помогает только увеличение ранга, это не подтверждает M-B. Если помогает любой остаток одинакового размера, это не подтверждает M-S.

## 2. Случаи и общий старт

MediaMill 1104/1114/1124, B = 507 700 / 507 070 / 507 385 байт. Полные ориентиры и их политики — из общего реестра; у 1124 ориентир качества содержит 160 деревьев.

Все новые методы начинают с одной и той же сохранённой функциональной компактной модели 80 деревьев из SR1. Начало включает плотный общий участок 40 деревьев и первый сжатый участок 40 деревьев, r = 50, остаток прежнего типа. Модель не обучается повторно; её сырой прогноз и цена перепроверяются.

Выбор функционального старта и 80 деревьев назначен до новой серии, одинаков для всех методов и не выбирается по прежнему тесту.

## 3. Архив и активный участок

Последние 40 новых деревьев — активный участок с собственным функциональным базисом ранга 50. Более ранняя функция — архив. На состояниях 120/160/200 деревьев архив содержит соответственно 80/120/160 деревьев.

У объединённых методов сохраняется не более двух разных декодеров: архивный и активный. Архив может включать прежний плотный начальный участок, поэтому это изменение требования абсолютной неизменности старых блоков SR2. Оно производится явно, через приближённое сохранение функции, с измерением ошибки и проверкой общего качества. Безусловная защита прежних массивов не объявляется сохранённой.

Учитель пересжатия — фактическая функция архива перед операцией. Он не подменяется полной исторической моделью. Направления будущего градиента не задают автоматически базис уже выученной функции. Для диагностики отдельно сохраняются ошибка архива и ошибка нового приращения, их сумма и согласованность.

Начальный архивный базис B0 строится функциональным PCA по прогнозам на обучающей выборке общих первых 80 деревьев без постоянного смещения. У обновляемого варианта тем же методом заново строится базис текущего архива. Среднее, классовые координаты и численная процедура одинаковы. Это одна заранее назначенная новая версия подпространства на пересмотр, без поиска нескольких удачных инициализаций.

Функциональный PCA минимизирует свой матричный суррогат; он не гарантирует F1. После выбора базиса координаты, среднее и остаток пересчитываются общей процедурой. Изменение направления оценивается по проектору, функции и метрикам, а не по числам отдельных столбцов.

## 4. Шесть новых методов

| ID | Архив | Направления архива | Поддержка остатка | Назначение |
|---|---|---|---|---|
| M-SEP | отдельные прежние группы | собственные функциональные B, r = 50 | balanced_mse | сопоставимый контроль без объединения |
| M-F | один архивный B, r = 50 | B0 неизменен | balanced_mse | общий архив с фиксированными направлениями |
| M-B | один архивный B, r = 50 | обновлять по текущей функции архива | balanced_mse | эффект направлений при том же ранге |
| M-S | один архивный B, r = 50 | B0 неизменен | квоты по дефицитам меток | эффект распределения остатка |
| M-BS | один архивный B, r = 50 | обновлять | квоты по дефицитам меток | первичный совместный метод |
| M-E64 | один архивный B, r = 64 | обновлять тем же способом | квоты по дефицитам меток | увеличение ранга вместо замены направлений при r = 50 |

Ранг активного участка остаётся 50 во всех методах, включая M-E64. Таким образом, последний контроль проверяет расход памяти на расширение именно архива. Для сопоставимых вариантов сетка квот, точность, решатель, геометрия активного участка и выходная политика одинаковы.

M-F/M-B/M-S/M-BS дают схему 2×2: фиксировать/обновлять направления и прежнее/новое распределение поправок. M-SEP проверяет необходимость объединения, M-E64 — необходимость увеличения размерности. Исторические четыре базиса SR2 показываются отдельно, не заменяют эти сопоставимые контроли.

## 5. Квоты остатка в байтах

Для данной структуры и базисов вычисляется максимально помещающаяся общая квота s_max по прежней физической оболочке. Учитываются все указатели и появление CSR-массивов, а не только цена одного значения. Квота делится между группами пропорционально числу их полноразмерных листовых коэффициентов; округление и перераспределение при исчерпании координат детерминированы.

На каждом пересмотре доступны квоты: 0, половина s_max, s_max и прежняя квота 5% полноразмерных коэффициентов, ограниченная фактической ёмкостью. Совпадающие варианты удаляются. Это до четырёх квот, без дополнительного поиска долей после результатов.

Сравнение двух правил поддержки внутри одинакового B/структуры/r делается при одинаковых квотах по группам и общей численности координат. Значения поправок, пересчёт A, среднее и численная процедура одинаковы; меняется правило адресации. Реальная память после пересчёта проверяется, нулевые значения и занятые позиции учитываются отдельно. Различающиеся размеры не называют чистым сравнением адресности.

## 6. Новая адресация: дефицит отдельной метки

Прежний balanced_mse уже учитывает баланс меток. Новая проверка касается распределения ограниченного числа координат между выходами.

Для временного учителя и основы без остатка на train вычисляются F1 каждой метки при **одних и тех же замороженных порогах предыдущего состояния**, настроенных только на calibration. В обоих случаях берётся полный прогноз ансамбля с общим смещением и новым участком, а не изолированное значение листа или архива. Учитель — прежняя фактическая модель плюс полное новое временное приращение; основа — предложенное представление той же суммы без новых поправок. Один вектор дефицитов применяется к распределению внутри обеих групп. Для метки j:

$$\delta_j=\max\{0,F1^{\mathrm{teacher,train}}_j-F1^{\mathrm{basis,train}}_j\}.$$

В пределах каждой группы квота s делится между метками пропорционально положительным δ_j методом наибольших остатков. Она ограничивается числом доступных ненулевых координат метки; неиспользованное перераспределяется тем же правилом. Внутри метки координаты выбираются прежним balanced_mse. При нулевой сумме δ применяется обычный глобальный balanced_mse, что записывается как отсутствие активации нового правила.

Это один конкретный вариант адресации. В первый пилот не добавляются другие степени частот, ширины окрестностей порога или подбор минимальной квоты по редкости. Редкость сама по себе не объявляется причиной ошибки. У меток без достаточной поддержки train неопределённость показывается явно.

Квоты основаны на train-диагностике и не используют test или ошибки отдельных меток на control для построения поддержки. Control проверяет готового кандидата общей тройкой метрик. После изменения поддержки выходная политика настраивается прежним общим способом, а не отдельно для каждого исправленного листа.

В диагностическом парном сравнении значения остатка и правило их пересчёта одинаковы; нельзя приписать новый способ подгонки значений эффекту адресации. Если после пересчёта фактический размер различается, сохраняются обе цены, а вывод об одинаковой памяти не делается.

## 7. Диагностика на сохранённых моделях

Вход — одна и та же сохранённая функциональная модель 160 деревьев каждого случая из SR2. Для архивных вариантов её первые 120 деревьев служат архивом, последние 40 — активным участком. Старый функциональный префикс 80 задаёт B0. Это условная проверка представления данной функции, а не воспроизведение ещё не обученной новой траектории.

Шесть методов × квоты 0/прежние 5%/максимальная допустимая ёмкость — до 18 представлений на случай, до 54 на три случая. Если варианты совпадают, они не повторяются.

Для M-F и M-BS при максимальной ненулевой квоте дополнительно проверяются пять случайных поддержек с зернами 701…705, при тех же ранге, квотах групп и правилах значений. Лучший случайный вариант не выбирается. Это до 30 дополнительных представлений, всего **до 84**. Если общей ненулевой квоты нет, контроль помечается неактивным, не отрицательным.

Проверяется: точная смена координат до ограничения ранга; ошибка самого ограничения; стоимость архива и декодеров; польза нового подпространства при r = 50; распределение s_j; F1 по меткам до/после; покрытие поддержки; NLL и обе F1 после общей настройки выходов. Тестовая часть не читается.

## 8. Последующее обучение

После старого старта 80 — до трёх новых предложений по 40 деревьев, максимум 200 суммарных. Глубина 3, минимум 10 объектов в листе, lr = 0.1, lambda_l2 = 1, subsample = colsample = 1. Глубина и число листьев здесь не являются дополнительными ручками; их меняет отдельная BR-N.

Зерно предложения: seed_case + 70000 + 40b, b = 1…3. Все шесть методов получают одинаковое правило зерна. При разошедшихся функциях строятся свои новые деревья, повторное использование чужого будущего приращения запрещено.

Каждый метод формирует варианты из одного нового полного временного блока. У архивных методов пересжатие прежнего архива оценивается вместе с этим новым блоком. Нет отдельной поблажки «ещё 5%» при каждом объединении. Принятие — по общему правилу: действительный B, полезность и неизменный глобальный ориентир. После квалификации требуется сохранение полного допуска.

M-F/M-S сохраняют B0 после первого объединения. M-B/M-BS/M-E64 предлагают один новый функциональный базис текущего архива на каждом объединении. Прежний базис остаётся диагностическим сравнением; количество реально изменивших подпространство событий обязательно публикуется. В первом объединении функции могут совпасть по направлениям; это не считается отдельным положительным эффектом обновления.

Следующее обучение получает прогнозы принятого архива и активного участка. Исходный полный учитель для градиентов не сохраняется. Состояния до и после каждого объединения доступны для независимого восстановления.

## 9. Основные сравнения и расширение

- M-F против M-SEP: цена общего архива, включая возможное искажение функции и сжатие начального плотного участка. Это не только устранение копий B.
- M-B против M-F и M-BS против M-S: новые направления при том же ранге.
- M-S против M-F и M-BS против M-B: адресация при сопоставимых квотах и памяти.
- M-BS против M-E64: обновление r = 50 и расход на больший r = 64 при том же B. Фактическая квота S может различаться и должна быть показана; это сравнение стратегий распределения, а не только геометрии.
- Адресные против случайных поддержек: польза адресации, не просто возврата коэффициентов.

Первичный метод — M-BS. Если помогает M-E64, а M-BS нет, сохраняется результат в пользу большего ранга, без вывода о достаточности обновления направлений. Если M-F не хуже остальных, сложность новых действий не оправдана этим пилотом. Если адресация не активировалась, гипотеза не считается опровергнутой.

По каждому случаю публикуется полный список меток с потерями и восстановлением F1, частотами train/control/selection, распределением поправок и признаками недостаточной поддержки. Тестовые разрезы считаются только после общего запечатывания, без повторного выбора меток и квот.

Шесть методов × три случая × максимум 120 новых деревьев = **2160 новых деревьев**, включая отвергнутые предложения. Старый старт 80 и полный ориентир не обучаются заново. После аудита и итоговой оценки остановиться для обсуждения. Расширение — по общему критерию, без автоматических новых наборов.

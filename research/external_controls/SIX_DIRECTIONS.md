# Шесть направлений HASBoost: код исследовательской серии

Серия выполнена 30 октября 2026 года, публикационная сборка подготовлена 2 ноября. [Результаты, таблицы и ограничения](../../docs/research/2026-10-30/README.md) находятся отдельно от прежней интерактивной инфографики. Старый HTML сохранён без изменения.

## Карта реализации

| Направление | Основные файлы | Назначение |
|---|---|---|
| R1 / R1A | `six_r1.py`, `six_r1a.py`, `six_common.py`, `six_train_profiles.csv` | Парные сравнения фактических байтов, восстановление сводки без повторного вычисления прогнозов, обучающие метахарактеристики |
| R2 / R2C | `six_r2.py`, `six_r2c.py` | Компактное начало, прямое обучение с выбранным остатком, расширение на прежние разбиения |
| R3 / R3C | `six_r3.py`, `six_r3c.py`, `six_structural_core.py` | Удаление деревьев, укрупнение листьев и обновление значений при фиксированной структуре |
| R4 | `six_r4.py`, `six_gather_gpu.py` | Packed против отдельного сбора координат и GEMM, исходный Py-Boost как ориентир |
| R5 / R5A | `six_quant_core.py`, `six_quant_gpu.py`, `six_mixed_quant.py`, `six_r5.py`, `six_r5a.py` | Физические FP16/INT8-массивы, CPU-эталон и раздельное квантование A/B/начала |
| R5Q / R5QM | `six_r5q.py`, `six_r5qm.py`, `quantized_direct_coordinate_gpu.py`, `quantized_direct_gpu.py`, `quant_metric_core.py` | Предварительный штраф координат и исправленный штраф в пространстве декодированных листьев |
| R5S / R5O | `six_r5s.py`, `six_r5o.py`, `fast_quant_gpu.py` | Стадии инференса, прямое преобразование FP16, перенос масштабов INT8 из внутреннего цикла |
| R6D / R6E / R6B | `six_r6d.py`, `six_r6e.py`, `six_r6b.py` | Каталоги с равным числом кандидатов, сильный обычный контроль, размещение и запросы банков |
| R6T | `six_r6t.py`, `saved_serving_core.py` | Прежние пять задач, сравнение готовых банков с кэшированным TabPFN, сохранение старых сдвигов порогов |
| R7 | `six_analysis.py`, `six_figures/` | Сведение закреплённых отчётов в таблицы и графики |

Внешний контроль находится в [`../nvforest_control`](../nvforest_control/README.md). Его зависимости несовместимы с нативной средой; они не устанавливаются в среду HASBoost.

## Безопасный вход и воспроизведение

`external_config.json` и все шаблоны `six_configs/*.json` имеют `phase=publication`. Вход `python external_runner.py` завершает работу с `publication_only` до обращения к GPU, установки пакетов и проверки весов. Файл `six_research_worker.py` сопоставляет только известные имена стадий с конкретными модулями; вызов отдельного научного модуля рассчитан на восстановленные исследовательские данные и не является публикационным входом.

Шаблоны сохраняют параметры исходных опытов и контрольные суммы, но пути помечены `${HASBOOST_ARTIFACTS}`, `${HASBOOST_NATIVE_ENV}`, `${HASBOOST_EXTERNAL_ENV}`, `${HASBOOST_NVFOREST_ENV}`. Эти строки сами не раскрываются. Для нового воспроизведения нужны отдельная рабочая копия, восстановление перечисленных артефактов с проверкой SHA-256 и явная конфигурация стадии. Старые замороженные узлы не редактируются. Модели, признаки, разметка, веса, ключи и окружения здесь не распространяются. Согласие на лицензию TabPFN не переносится вместе с исходниками.

Нативная среда: Python 3.10, CuPy 13.3.0, NumPy 2.2.6, SHA-256 описания `634d173ce93429e267a57122d1594073b48b9ef25cd410d10798b144c32a6f42`. Внешняя среда TabPFN: Python 3.12.12, PyTorch 2.13 + CUDA 12.6, TabPFN 9.2.0, SHA-256 `34588579bac49b4f49adf00f22459b84040c799c9bcd2d21b78c4821c139cbb7`. Исходный ориентир Py-Boost — неизменённый `master @ b2842af472e21c7332d9487d8c83e53cb48d1486`.

`six_source_provenance.json` связывает опубликованные модули с коммитами завершённых узлов. Хеши текста вычислены для UTF-8 с LF. В публикации отдельно исправлено завершающее преобразование NumPy-числа в JSON у R1, переименованы исторические варианты, удалены лишние пустые строки в конце трёх модулей и добавлены инертные входы. Научные прогнозы и замороженные отчёты не пересчитывались.

## Проверки без GPU

Из `research/external_controls`:

```text
python ../../tools/hasboost_cpu_tests.py -q tests/test_six_residual_gate.py tests/test_six_structural.py tests/test_six_quant.py tests/test_six_mixed_quant.py tests/test_quant_metric.py tests/test_packed_serving_core.py tests/test_direct_leaf_core.py tests/test_saved_serving_core.py
python external_runner.py
```

Проверки охватывают структурное сокращение, обновление листьев, поддержку остатка, физический размер и CPU-декодирование кодеков, метрику неортогонального B, упаковку и перенос старых порогов. Серверные измерения описаны как результаты прежних запусков; локальная CPU-проверка не считается новым GPU-бенчмарком.
